## 自动检查

- 从清洁源码运行 `npm ci`、`npm run setup:runtime`、`npm run doctor`、`npm run typecheck`、`npm test`。
- 执行 `npm run build`，确认 NSIS 安装程序与便携版均产生，检查未自动发布。
- 执行 `npm audit --audit-level=high`；区分构建依赖和实际运行时，但不得掩盖高危项。
- 执行 `npm run public:check`，审阅路径、规则和计数，再导出源码 ZIP。
- 检查包内仅有程序、生产依赖、图标和许可证，不含源码工作目录、个人配置或登录态。
- 检查 LICENSE、NOTICE、第三方许可证齐全，保留“欧俊言律师”署名。
- 清洁源码包含 README.en.md 与 docs/LICENSE.en.md；英文译本不替代中文 LICENSE。
- 显示名统一为知幕 / Zhimu Player，包名使用 `Zhimu-Player-1.2.0-rc.8-*`，程序和源码版本一致，README 明确候选状态。
- 项目更名不改变许可 1.0 的授权、限制与署名要求；旧名时期的验证记录保留历史原文。

## 实机路径

- 新 Windows 用户或隔离的用户数据目录中完成首次引导，未继承开发者账号。
- 使用隔离的旧版数据样本验证升级恢复；内部 `com.videoplayer.app`、`video-player`、localStorage 协议键和 `ai-video-player-guide:` 不因更名被替换，原设置和播放状态可继续读取。
- NSIS 可以选择安装目录、无需管理员安装；启动/退出/卸载行为符合预期。
