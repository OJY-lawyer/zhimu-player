# 知幕 Zhimu Player 登录与故障处理

适用于 `1.2.0-rc.10` 候选版，下载见 [GitHub Release](https://github.com/OJY-lawyer/zhimu-player/releases/tag/v1.2.0-rc.10)。项目从 AI Video Player 更名后继续使用原来的用户数据
目录与登录配置；无需因更名导出 Cookie 或重新复制浏览器资料。登录是否仍有效由
服务方实际会话决定；本候选版实际登录和短导读的验证范围见 [rc.10 版本说明](./RELEASE-1.2.0-rc.10.md)。

## ChatGPT 网页

如果旧候选版显示「Edge 调试通道已经关闭」或点击登录没有窗口，请更新到当前候选版。
程序已处理 Windows 下 Edge 启动进程转交后的连接问题，并恢复可见窗口位置。
后台检查与生成使用随机本机端口，不开放局域网访问；人工登录阶段不启用调试连接。

网页版无需安装、登录或交由 Codex 运行。先在设置中选择 ChatGPT 网页，连接区直接提供
“打开登录窗口”“导入 Cookie”“检查连接”三个按钮。完成登录并检查连接后，再自行选择网页模型和推理档位。

### 普通专用窗口登录

点击“打开登录窗口”，确认域名是 `chatgpt.com` 或服务方正式登录页面，自己完成账号
登录和验证码。关闭这个播放器专用窗口后回到设置，点击“检查连接”。日常 Edge 不需要
关闭；该入口会继续保留，不要求用户必须导出 Cookie。

Google 可能阻止软件自动控制的浏览器登录。rc.7 已将人工登录与后台自动连接分开，
不会在 Google 登录阶段连接 CDP 或自动操作网页。如果上次受控的播放器专用 Edge 仍开着，
请先关闭它再打开普通登录窗口。旧窗口运行时，新启动可能仍被旧进程接管。
若已经完成登录但“检查连接”提示未就绪，先关闭播放器专用 Edge 后再检查。
日常 Edge 的登录状态与播放器独立；现版没有直接接管日常浏览器的扩展通道。

### 导入已有浏览器会话

如果日常浏览器已经能正常使用 ChatGPT，可主动导入自己的导出文件，不需要复制整个
浏览器配置，也不读取日常浏览器的 Cookie 数据库：

1. 在已登录的 **chatgpt.com 页面**使用 Cookie-Editor 导出 JSON。应导出 ChatGPT 网站的
   Cookie，而不是 Google、其他应用或整个浏览器的全部网站。
2. 回到播放器设置，点击“导入 Cookie”，选择“从 JSON 文件导入”，
   或复制导出内容后选择“从剪贴板导入”；也可点击“粘贴 JSON”，在输入框粘贴后导入。无需把内容发到 agent 对话里。
3. 导入时会自动检查连接；结果未知时可稍后手动点击“检查连接”。导入数量只说明本机写入步骤，不代表账号已经认证。
   导出的会话若过期或被服务方撤销，重新登录后再导出。

限制与处理：只接受 Cookie-Editor JSON 数组或带 `cookies` 列表的对象；输入上限
**2 MiB / 2000 条**。只接收 `chatgpt.com` 及子域中符合格式与有效期要求的条目，跳过
无关域、过期或不合法条目；分区 Cookie 不会被扩大为普通 Cookie。文件和剪贴板内容不会回显；
手动粘贴的内容临时显示在输入框内，提交、关闭或切换来源时清空，不写入配置。诊断不包含 Cookie 秘密值。
请自行保管导出文件，不要上传到 GitHub、问题反馈或聊天。

导入针对播放器专用会话的相关条目，不清空其他网站的 Cookie。发生中途失败时会尝试
恢复受影响的旧条目；浏览器断开等情况可能妨碍完整恢复，遇到明确的恢复失败提示时，
请在专用窗口检查或重新登录。普通登录始终是可选入口。

### 模型和推理档位

“网页模型”和“推理档位”分开选择，不再按 Plus/Pro 固定模型。内置预设只是候选项，
不能证明账号实际可用。登录后可以点击“从 ChatGPT 刷新可用选项”读取菜单；刷新不自动替换原选择，
已有有效选择继续保留，缺少选择或无法确认可用时才需要重新选择。当前网页无可读档位选项时显示“按网页默认”，不据此判断其他模型的能力。

本机实际菜单已核对 GPT-5.6 Sol 的 Instant、Medium、High、Extra High、Pro，以及 GPT-6 Astra 的 Pro。
“最新”入口的其他档位没有明确模型家族标识时，不会被推断成 Astra。Sol Pro 和 Astra Pro 的切换已验证，
实际完整短导读只用 Sol Medium 生成过；这不能证明所有档位均能生成。

登录成功只说明会话可用。指定模型和推理档位仍需在实际生成时核对；账号没有对应
选项、次数耗尽或页面变化时，播放器会停止并显示错误。可在登录窗口检查账号或
稍后重试，也可由用户明确改选另一来源。不会自动动用 Codex 或 API 额度。

### 检查连接没有结果时

播放器区分“已登录”“尚未登录”和“暂时无法确认”。网络错误、超时、人机验证或页面
没有加载完成都属于未知状态，不等于账号掉线，也不会自动清除登录资料。若曾确认过
登录，会保留该记录，同时在连接区显示本次检查的具体原因；这也不代表本次生成已经可以继续。
若提示 403，打开普通专用登录窗口完成网页安全验证，确认能聊天后关闭该窗口再检查。Cookie 已写入时不要因这类提示重复导入；仅在服务端明确要求重新登录时更新会话。

## DeepSeek API

在设置中选 DeepSeek，填写自己的 Key，离开输入框后从自动获取的列表选择模型并保存。
可用“刷新模型”重试；当前模型不在列表中时会提示，不会自动替换。兼容接口不支持
列表时可在高级设置手动填写。临时故障下的缓存仅属于本次启动、同一接口和 Key。
鉴权失败先核对 Key；额度或模型权限失败先在服务方账号中检查。
不要在 issue、聊天、截图或诊断日志中展示完整 Key。

## 听悟

在首次引导或设置中打开听悟登录窗口，自己完成登录后返回检查。登录会话与播放器
关联，不需要安装扩展或导出 Cookie。退出、登录过期、风控或账号服务权限变化后，
重新在该窗口登录再重试。

旧版账号密码页若显示“500 / header value … is not allowed”，或点击“阿里云盘”没有弹窗，
请更新到当前候选版。当前版修正了浏览器标识，并允许云盘独立登录授权窗口；弹窗与主窗
使用同一听悟会话。关闭子窗口不会退出账号；只有主动“退出听悟”才清除本地听悟会话。

按视频实际语音选择中文或英语；切换播放器界面或导读语言不会改动这项选择。
播放器英文界面不会翻译听悟服务方的登录页；账号和地区是否可用以服务方实际提供
的页面为准。无法完成登录时，可使用本地已有 SRT，不影响本地播放。

已有字幕可以直接使用，听悟不是本地播放的前置条件。点击生成字幕才会上传媒体。
内置流程保存 SRT，不另外导出转写 Markdown。取消本地等待不会删除云端已经创建的
记录；如需删除，请在听悟页面自行管理。

## 常见问题

| 现象 | 下一步 |
|---|---|
| 找不到 Microsoft Edge | 安装或修复正式 Edge，或明确选 DeepSeek API |
| 登录窗口仍要求登录 | 完成验证码，返回播放器重新检查 |
| ChatGPT 显示暂时无法确认或检查超时 | 检查网络、完成人机验证后再试；未知状态不等于退出，不需要立即重复导入 |
| Cookie 文件、剪贴板或粘贴内容无法导入 | 查看连接区具体错误，核对 JSON 格式、2 MiB / 2000 条限制及是否来自 chatgpt.com，不要发送导出内容给支持人员 |
| 模型或推理选项找不到 | 检查实际账号权益；保留错误阶段供适配，不暗中降级 |
| 字幕生成失败 | 检查听悟登录、上传权限、网络与视频目录写入权限 |
| 已有同名 SRT 为空或无效 | 原文件会保留；先更名备份，再重试，不能仅凭文件存在判断转写成功 |
| 视频打不开或无声音 | 容器扩展名不代表编码可播放；尝试兼容编码的视频 |
| rc.8 中字幕或进度条点击后又回原处 | rc.9 修复了未缓存完时的媒体分段读取；升级后仍异常时提供版本、格式和操作步骤，不必上传私人视频 |
| 窄播放区看不到音量条或按钮滚轮无效 | rc.9 按实际播放区适配音量条，视频/音量按钮/音量条均支持滚轮；核对运行版本 |
| 旧的多视频导读无法点击跳转 | 原 Part 对应记录缺失，不能从当前顺序可靠恢复；仍可阅读，重新生成导读可恢复跳转 |
| 部分导读时间戳无法跳转 | 检查视频是否改名、移除或重名；无法唯一匹配的链接会停用 |
| Windows 显示发布者未知 | 当前构建未签名；核对下载来源及 SHA-256，再决定是否运行 |
| 应用已叫知幕，但用户数据目录仍是 video-player | 这是为了保留旧版设置和登录态的兼容安排，不需要改名或删除 |
| 界面是英文但字幕或旧导读仍是中文 | 界面切换不会翻译用户内容；选择英文导读语言后生成新版本 |
| 切换导读语言后已有版本未改变 | 语言设置仅用于下一次生成；已有版本保持原文 |
| 英文界面出现 Additional details 和中文内容 | 这是尚未映射的服务详情或错误原文，保留它以便排查，不表示任务成功 |

反馈问题时提供程序版本、Windows 版本、所选来源、步骤和错误文字。截图先遮住账号、
文件名等个人内容；不要上传用户数据目录、浏览器配置、视频、Cookie 或 Key。

## 当前验证边界

rc.10 已通过真实 Edge 的 15 项合成 Cookie 协议检查；实际账号由用户完成网页安全验证后，
多次重启专用浏览器仍通过服务端登录检查。Sol Medium 已完整生成并取回一份带时间戳的短合成文本导读。
25 个离线测试文件、类型检查、构建和 19 项真实 Electron 播放检查通过。本机 rc.10 覆盖升级已验证保留设置、播放记录和两种登录文件共 4 份数据。
这不等于长字幕或附件上传、Pro 等其他档位生成、听悟新任务、其他机器或 GitHub 增量更新已验收；rc.10 仍为候选版，并非稳定版。
